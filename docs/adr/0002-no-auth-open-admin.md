# Без аутентификации, админка открыта

Регистрации, входа и личных кабинетов нет: записаться может любой, а админка (типы событий и список предстоящих записей) доступна без входа. Альтернативой была авторизация как в Cal.com, но она противоречит ТЗ. Главное следствие: админка не защищена — приемлемо только для учебного проекта, в проде потребуется хотя бы базовая аутентификация.
