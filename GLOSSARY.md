# Calendar

Сервис записи на звонок по мотивам Cal.com: Хост публикует время, Гость выбирает свободный слот и записывается на него. Без авторизации и личных кабинетов; в README проект называется «Календарь звонков».

## Language

**Хост**:
Человек, чей это календарь: публикует время, управляет типами событий и видит предстоящие записи.
_Avoid_: владелец, админ, оператор, специалист
English: `Host`

**Тип события**:
Вид встречи с названием, описанием и длительностью в минутах (любое положительное число, задаёт Хост), на который идёт запись.
_Avoid_: услуга, категория, формат
English: `EventType`

**Слот**:
Начало возможной записи в сетке календаря на ближайшие 14 дней; бывает свободным или занятым. Свободен ли слот, зависит от длительности выбранного Типа события: запись занимает все ячейки сетки от начала до конца этой длительности.
_Avoid_: окно, период, расписание
English: `Slot`

**Гость**:
Тот, кто записывается на Слот; учётной записи у него нет.
_Avoid_: пользователь, клиент, посетитель
English: `Guest`

**Запись**:
Факт выбора Гостем Слота: занятый слот с заметкой Гостя.
_Avoid_: бронь, бронирование, заказ, регистрация
English: `Booking`

_«Бронирование» допустимо только в дословных строках из спеки («Забронируйте встречу за минуту», «Быстрое бронирование с подтверждением и дополнительными заметками», «Базовый тип события для бронирования.»); в новых русскоязычных текстах — «запись». Английские имена сущностей для API (строка `English`) под запрет не попадают._
